# Security policy

This policy covers every repository under [github.com/combor](https://github.com/combor) that has no security policy of its own.

## Reporting a vulnerability

Report security problems privately: open the affected repository's **Security** tab and choose **Report a vulnerability**. This opens a private advisory that only you and the maintainer can see.

Please don't open a public issue or pull request for a security problem.

Include what you found, the version or commit you tested, and the steps to reproduce it. Follow-up happens in the advisory, and the advisory is published once a fixed release is out.

## Supported versions

Security fixes go into the latest release of each project. Older releases are not patched.
